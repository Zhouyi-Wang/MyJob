# 📂 Experiments & Test Scripts

Experimental scripts and test cases for PINN research.

## 📁 Files

| File | Purpose |
|------|---------|
| `example.py` | Basic usage example for PINN implementations |
| `test_optimization.py` | Tests for optimization algorithm variants |
| `test_convergence.py` | Convergence studies across hyperparameters |

## 🎯 Usage

Run any experiment script directly:

```bash

python example.py

# Optimization tests
python test_optimization.py

# Convergence study
python test_convergence.py
```
